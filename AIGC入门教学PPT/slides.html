WHAT IS AIGC
03 / 20

不是替代人，
是放大表达。

TEXT · IMAGE · VIDEO · AUDIO
AIGC 概述
GENERATE / EDIT / COMPOSE
生成内容
把想法转成文案、图像、视频、音乐、代码或多模态素材。
协同创作
人负责目标、判断、审美与责任；AI 负责起草、发散、改写和批量变体。
工作流工具
真正有价值的不是单个工具，而是“脚本 → 画面 → 视频 → 发布”的组合。

SCRIPT TOOLS
06 / 20
创意脚本

先让大模型帮你把想法说清楚

ATOOLS
Gemini / ChatGPT / 豆包

适合用来做选题发散、脚本结构、分镜描述、口播润色、标题改写。

  • 让它扮演“策划 + 导演 + 审稿人”
  • 一次给出多版本，不要只要一个答案
  • 要求输出表格，方便进入下一步
BPROMPT
基础提示词公式

角色 + 任务 + 背景 + 受众 + 格式 + 约束 + 示例。

  • 不要说“帮我写一个脚本”
  • 要说“面向谁、几分钟、什么风格、输出什么表”
  • 让模型先问 3 个澄清问题也很有效
PROMPT METHOD
07 / 20
提示词不是咒语，是需求说明书

四步把 AI 从“会聊”变成“会干活”

01
定角色
你是短视频编导 / 品牌策划 / 课程老师。
02
给背景
产品、受众、平台、风格、时长、素材。
03
定格式
用表格输出：镜头、画面、台词、字幕、音效。
04
给标准
不能夸大、避免空话、每句少于 18 字。

IMAGE EDITING
09 / 20
编辑修改

好图往往不是一次生成，而是反复修出来

01BANANA
局部编辑 / 风格延展

适合把已有图片做局部重绘、替换元素、保持主体同时改变背景或风格。

  • 圈出问题区域
  • 描述要替换成什么
  • 保留主体一致性
02IMAG2
扩图 / 修补 / 变体

适合给画面补边、修小瑕疵、生成多版候选，再交给人挑选。

  • 先保真，再创意
  • 不要一次改太多
  • 每次只验证一个目标

剪辑与音乐

把 AI 生成的片段变成可发布的视频：定节奏、补字幕、加转场、做封面。

音乐与情绪

用一句话定义风格、速度、情绪和用途，生成主题歌或背景音乐。

  • 先定情绪：轻快 / 悬疑 / 温暖
  • 控制时长与是否人声
  • 确认版权与发布场景

RISKS & RULES
19 / 20
新手最容易踩的坑

越快，越要慢一步检查

01
事实错误
AI 会把听起来合理的内容说得很真。涉及数据、人物、机构必须查证。
02
版权与肖像
商用前确认素材来源、授权范围、人物肖像和音乐使用规则。
03
品牌安全
不要生成误导性承诺、敏感场景、侵权 logo 或不合规宣传。
人工判断 是最后一道质量门

AIGC STARTER COURSE
课后任务
03 RULES
01

用同一个主题做 3 版脚本

比较不同模型或不同提示词的差异。

02

生成一组视觉参考

保留提示词、失败版本和最终选择理由。

03

把作品交给真实标准检查

可读、可信、好看、可发布，四项都过才算完成。
